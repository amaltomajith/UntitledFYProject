Token Efficiency Analytics

Comparative analysis of Puppeteer++ adaptive multi-agent orchestration vs. four baseline LLM methods across 5 fixed reasoning tasks.

R_t = γ · R_{t+1} − λ · C_t + β · s_t  |  C_t = F_t · log(1 + t/φ)
📋
What this measures: For each of 5 fixed benchmark tasks (Math Reasoning, Logic Puzzle, Rate Problem, Code Analysis, Multi-step Planning), we count the total tokens consumed by each method end-to-end. Puppeteer++ uses an adaptive selector policy π to activate only the agents needed, reducing wasteful computation while maintaining accuracy. Baselines include: Monolithic LLM (single large model), Fixed Multi-Agent (all agents always run), Chain-of-Thought, and ReAct.
